# 🌩️ Cloud Conquest - AWS Treasure Hunt Game

Welcome to **Cloud Conquest**, an interactive AWS-themed treasure hunt game designed to test your cloud computing knowledge while exploring different locations. Navigate through 5 challenging stations, solve puzzles, and earn badges as you master AWS concepts!

## 🎯 Game Overview

Cloud Conquest is a location-based puzzle game where players progress through 5 stations, each with unique challenges related to AWS services and cloud computing concepts. Players must physically visit locations, scan QR codes, and solve puzzles to advance.

### 🏆 Game Objectives
- Complete all 5 stations in sequence
- Earn badges for each completed station
- Learn AWS services and cloud computing concepts
- Achieve 100% completion and earn your certificate

### ⏱️ Game Rules
- **Time Limit**: 2 hours (120 minutes) to complete all stations
- **Sequential Progress**: Stations must be completed in order (1 → 2 → 3 → 4 → 5)
- **QR Code Requirement**: Each station requires scanning a specific QR code to unlock
- **One Attempt**: Each QR code can only be scanned once
- **Anti-Cheat**: Rapid submissions and suspicious activity are monitored

## 🗺️ Station Guide & Solutions

### Station 1: Welcome Station ☁️
**Location**: Cour (Courtyard)  
**Badge**: Cloud Explorer  
**QR Code**: "AWS"

#### Challenge: Cloud Computing Riddle
A simple introductory riddle about cloud computing concepts.

#### How to Complete:
1. Find and scan the QR code containing "AWS" in the Courtyard
2. Read and understand the introductory riddle
3. Click "Complete Station" (no specific answer required)

---

### Station 2: Knowledge Hub 📚
**Location**: Library  
**Badge**: AWS Scholar  
**QR Code**: "Builders"

#### Challenge: AWS Service Matching
Match AWS services to their correct descriptions in an interactive drag-and-drop interface.

#### Services to Match:
- **Amazon S3**: Object storage service
- **AWS Lambda**: Serverless compute service
- **Amazon EC2**: Virtual servers in the cloud
- **Amazon RDS**: Managed relational database service
- **Amazon CloudFront**: Content delivery network
- **AWS IAM**: Identity and access management

#### How to Complete:
1. Scan the QR code containing "Builders" in the Library
2. Drag each AWS service to its correct description
3. Ensure all 6 services are correctly matched
4. Click "Check Matches" to validate
5. Complete the station (answer validation: "aws-services-matched")

---

### Station 3: Navigation Challenge 🧭
**Location**: Corridor  
**Badge**: Path Finder  
**QR Code**: "Free"

#### Challenge: Word Finding Challenge
Find QR codes containing specific words to form a phrase about AWS Cloud Clubs.

#### How to Complete:
1. Scan the QR code containing "Free" in the Corridor
2. Find and scan 5 QR codes containing specific words (in any order)
3. Discover the words to form a complete phrase about AWS Cloud Clubs
4. All 5 words must be found to complete the challenge
5. Complete the station (no specific answer required)

---

### Station 4: Discovery Zone 🔍
**Location**: Cafeteria  
**Badge**: Clue Hunter  
**QR Code**: "Lambda"

#### Challenge: Find the Lambda Burger
Search through the cafeteria menu to find the special AWS Lambda-themed burger item.

#### The Target Item:
- **Lambda Burger**: Serverless burger that scales automatically with your appetite

#### Other AWS-themed Items (Distractors):
- **S3 Bucket Fries**: Crispy fries served in a storage container
- **EC2 Instance Coffee**: Virtual blend of premium beans, scalable size
- **RDS Relational Soup**: Managed database of vegetables and broth
- **CloudFront Delivery Pizza**: Fast delivery from our global kitchen network
- **IAM Identity Sandwich**: Access-controlled layers with permission-based toppings

#### How to Complete:
1. Scan the QR code containing "Lambda" in the Cafeteria
2. Examine the cafeteria menu carefully
3. Click on the Lambda Burger (avoid selecting regular menu items)
4. Submit your selection to complete the station

---

### Station 5: Final Challenge 🏆
**Location**: Amphitheatre  
**Badge**: Cloud Master  
**QR Code**: "S3"

#### Challenge: AWS Architecture Builder + Final Question
Build a complete web application architecture using AWS services, then answer a final question.

#### Architecture Components to Arrange:
1. **User/Client** (starting point)
2. **Amazon CloudFront** (CDN)
3. **Application Load Balancer** (traffic distribution)
4. **Amazon EC2** (compute instances)
5. **Amazon RDS** (database)
6. **Amazon S3** (storage)

#### Correct Architecture Order:
```
User/Client → CloudFront → Load Balancer → EC2 → RDS
                                        ↓
                                       S3
```

#### Final Question:
**"Complete this phrase that celebrates the AWS community and highlights two key services: 'AWS Builders Build Free with _____ and _____'"**

**Answer**: "AWS Builders Build Free with Lambda and S3"

#### How to Complete:
1. Scan the QR code containing "S3" in the Amphitheatre
2. Drag AWS components to build the architecture
3. Arrange components in the correct order (User → CloudFront → Load Balancer → EC2 → RDS, with S3 connected to EC2)
4. Click "Check Architecture" to validate
5. Answer the final question: "AWS Builders Build Free with Lambda and S3"
6. Submit your answer to complete the game
